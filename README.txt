# Personal Website

## Overview
This repository contains the source code for my personal website which serves as a hub that showcases my resume, experience, skills, and travels as a somputer science and data science student at the University of St. Thomas

This website was built based on a template by HTML5 UP, and was made so I could practice my front end development skills while creating a real world artifact to be viewed by friends, family, peers, and employers.

## Installation Instructions
To run this website locally, you will need:

- A modern web browser (Chrome, Firefox, or Safari)
- (Optionally) a local development server

Steps:
1. Clone the repository:
2. Navigate to the project directory.
3. Either:
- Open `index.html` directly in a web browser, **or**
- Launch the site using a local development server for best results.

No additional dependencies or build steps are required.

## Usage Instructions
The website is intended to be used as a public-facing portfolio. Visitors can navigate through the site to learn about my background, view highlighted projects, and access links to external resources such as my GitHub profile or résumé.

This site can be found at the domain nickfrundt.com

The site is fully static and does not require user authentication or special configuration to use.

## Technologies Used
- HTML5
- CSS, SCSS
- JavaScript
- GitHub Pages (for deployment)

This website was made as a personal project outside of any academic or professional setting.
